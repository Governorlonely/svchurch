# svchurch

Сайт трёх церквей. Исходники и готовая автономная страница лежат в [`site/`](site/README.md), оригиналы пользовательских вложений — в `uploads/`.

## Запуск и сборка

```sh
cd site
python3 server.py        # предпросмотр на http://localhost:3000
python3 build.py         # пересобрать index.html после изменений исходников
node tests/content.cjs   # проверки страниц и направлений пожертвований
```

Подробности о структуре, функциях и том, что нужно сделать перед публикацией, — в [site/README.md](site/README.md).
