# Сайт трёх церквей

- `index.html` — актуальный сайт: автономная HTML-страница со встроенными стилями, кодом, изображениями и шрифтами. Можно открыть в браузере без сборки.
- `shell.html` — исходный каркас страницы и меню.
- `app.js` — содержимое страниц, навигация и интерфейсная логика.
- `style.css` — оформление и адаптивность.
- `assets/` — используемые логотип, фото и шрифты с имеющимися уведомлениями об авторских правах. Эти уведомления не заменяют веб-лицензию. `hero-church.jpg` — сгенерированное изображение для первого экрана; при наличии реального фото замените его и пересоберите `index.html`.
- `build.py` — сборка исходников в `index.html` (Python 3, без дополнительных библиотек).
- `server.py` — сервер предпросмотра на порту 3000 с отключённым кешированием.
- `tests/content.cjs` — проверки страниц и направлений пожертвований (Node.js).

## Изменения и запуск

После редактирования исходников:

```sh
python3 build.py
```

Для предпросмотра из папки `site`:

```sh
python3 server.py
```

Проверки:

```sh
node tests/content.cjs
```

В `../uploads/` сохранены оригинальные пользовательские вложения. Старые HTML-копии и временные скрипты удалены. Старые адреса предпросмотра `/glass.html`, `/updated.html`, `/layout-v3.html` и `/actay.html` обслуживаются сервером как актуальная главная страница.

## Перед публикацией

Нужно подключить отправку формы, добавить юридические тексты и сведения о получателях, проверить веб-лицензии шрифтов. Каталоги видео, событий и материалов пока не подключены к внешним источникам. Неизвестные сведения оставлены подписями. Платёжные ссылки предоставлены заказчиком; поле суммы на сайте их не изменяет.
